02 / METHOD

Rewrite, check, repair.

  1. Rewrite six sections with full context
  2. Independently check each section
  3. Repair specific meaning changes
  4. Verify the complete proposal
  5. Keep the candidate or restore the original

What this package includes.
The desktop app runs proposal generation, section revision, independent audits, bounded repairs, retention and local records. It uses Python’s standard library and runs on Windows and macOS. Section rewriting runs on the local Qwen model by default. Initial drafting, verification and repairs use your selected review account or endpoint. A hosted-only writer can be selected explicitly.
Repairs are limited to three non-overlapping patches per section and 35% of matched original characters. Final length must remain within 85–115% of the input. Content checks must pass; the independent reviewer must not judge readability worse.
The ledger records editing evidence within the current run; historical cards are not retrieved. The optional Qwen research profile and its recorded measurements are separate from each new desktop run. Inspect the model, input and audit records for the run you are evaluating.
