# Known-answer semantic-audit extension

This extension evaluates the released whole-document semantic auditor on exactly the 24 existing constructed mutation cases: 12 content violations and 12 legitimate paraphrases. No new examples are selected after seeing checker outcomes. The original deterministic guard outcomes were already observed before this extension was specified; the extension is therefore not described as an independently selected held-out benchmark. No semantic-audit outcomes had been observed at the extension freeze time.

The reference labels come from the explicit single edit and its known meaning relative to the frozen original. Examples include changing a negation, exchanging sample size and duration, changing a conjunction to a disjunction, swapping metric denominators, or expressing a number in words without changing its value. These source-relative labels do not require an external domain truth claim.

Every case is submitted to the unchanged full-audit instruction in `engine/core.py`, using gpt-6.1-sol through the official signed-in CLI. The auditor receives the original, candidate, source packets and section headings. It does not receive the expected pass label, the mutation explanation or the previous guard decision. There is one audit call per case; failed transport calls are preserved and may be resumed without modifying the input. No generation, repair or detector calls are made for this component test.

The semantic checker passes a candidate only when `contentPreserved` is true and its issue list is empty. Readability is reported but is excluded from the content-preservation confusion matrix because a benign edit can be faithful without being stylistically preferable. Report the confusion matrices for (a) the deterministic guard, (b) the semantic auditor, and (c) their conjunction. A positive reference label means a violation that should be rejected. Report sensitivity, specificity and accuracy with the denominator and Wilson intervals. Preserve all 24 outcomes, including false positives and incomplete calls.

This tests the coverage of specific checker components on known mutations. It is not an estimate of error rates on naturally occurring manuscripts, and it does not establish end-to-end writing quality. The conjunction may inherit a lexical false positive even when the semantic auditor correctly accepts a valid paraphrase; that result is retained rather than removed from the score.
