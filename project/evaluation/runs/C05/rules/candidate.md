# Museum Descriptions without Invented Provenance

## Abstract

Museum descriptions should avoid making uncertain object histories sound settled. We propose revising catalogue prose into concise public descriptions using only the supplied entry and curator note. The evaluation will assess readability alongside the preservation of approximate dates, disputed locations, and unknown makers [S2]. No new provenance research will be conducted.

## Introduction

A concise description can unintentionally remove the qualification that makes a historical statement defensible. For example, an approximate date should not become precise merely because the new sentence reads more smoothly. A blank maker field does not establish that an object was made anonymously [S1]. These distinctions concern evidence, not just editorial style.

## Related Work

The catalogue brief restricts the writer to using only the entry and its curator note [S1]. The evaluation brief specifies that three types of uncertainty—uncertain dates, disputed locations, and unknown makers—must remain visible [S2]. We will consider these qualifications as integral content and not count them as unnecessary hedging when an editor assesses whether a revision is more concise.

## Methodology

We plan to study 28 objects with varying combinations of uncertain dates, disputed locations, and missing maker information [S2]. Each description will be revised from the same source packet. Reviewers will compare the revised version with the original prose and identify the source phrase that supports each historical claim. Unsupported detail will remain an error, even if it makes the account more vivid.

## Planned Evaluation

The evaluation will ask readers to determine which version is easier to follow and curators to confirm whether each qualification is preserved. These assessments will be reported separately, not combined into a single quality score. Difficult cases will involve entries where a later note disputes an earlier location. The revised description must present the disagreement clearly without taking a side unsupported by the packet.

## Limitations and Conclusion

The source records may be incomplete or inconsistent, and clearer prose cannot resolve these gaps. We will not infer a maker from a missing field or treat an approximate date as exact [S1]. The intended contribution is an editing procedure that makes the limits of an object description readable, rather than concealing them behind confident wording.
