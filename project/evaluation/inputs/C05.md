# Museum Descriptions without Invented Provenance

## Abstract

Museum descriptions need to be readable without making an uncertain object history sound settled. We propose to revise catalogue prose into concise public descriptions using only the supplied entry and curator note. The evaluation will examine readability together with the preservation of approximate dates, disputed locations and unknown makers [S2]. The study will not undertake new provenance research.

## Introduction

A short description can unintentionally remove the qualification that makes a historical statement defensible. For example, an approximate date should not become a precise one merely because the new sentence reads more smoothly. A blank maker field also does not establish that an object was made anonymously [S1]. These distinctions concern evidence, not just editorial style.

## Related Work

The catalogue brief limits the writer to two supplied records: the entry and its curator note [S1]. The evaluation brief identifies three kinds of uncertainty that must remain visible [S2]. We will treat those qualifications as part of the content. They will not be counted as unnecessary hedging when an editor assesses whether a revision is more concise.

## Methodology

We plan to study 28 objects with different combinations of uncertain dates, disputed locations and missing maker information [S2]. Each description will be revised from the same source packet. Reviewers will compare the revision with the original prose and identify the source phrase that supports each historical claim. Unsupported detail will remain an error even if it makes the account more vivid.

## Planned Evaluation

The evaluation will ask readers which version is easier to follow and ask curators whether each qualification survives. These judgments will be reported separately rather than combined into a single quality score. Difficult cases will include entries in which a later note disputes an earlier location. The revised description must make the disagreement understandable without choosing a side unsupported by the packet.

## Limitations and Conclusion

The source records may themselves be incomplete or inconsistent. Clearer prose cannot resolve those evidential gaps. We will not infer a maker from a missing field or treat an approximate date as exact [S1]. The intended contribution is an editing procedure that makes the limits of an object description readable, rather than concealing them behind confident wording.
