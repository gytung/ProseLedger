# Evaluation

The recorded batch consists of six independently generated proposal drafts. Case IDs denote manuscripts, not scoring criteria. The three revision routes operate on the same initial text within each case.

The full table is in the README and `summary.csv`; manuscript texts and all 54 branch decision records are in `evidence.json`. Shared first revisions appear in each branch record and should not be counted as separate physical calls.

## Results

- Initial mean severity: 8.4000.
- Targeted mean severity: 6.8833.
- Planner-only mean severity: 7.0000.
- Memory mean severity: 7.1167.
- Memory versus Targeted: 0 wins, 4 ties, 2 losses.
- Memory versus Planner-only: 0 wins, 5 ties, 1 loss.

Both Targeted and Memory improve four initial drafts and tie on two. This is a within-batch observation. The retention rule already enforces non-increase. No same-batch external baseline, statistical significance or general superiority is established.

## Interpretation

Experience reached the Memory writer in four cases. Injection, execution, adoption and incremental benefit are separate events. In Case 02, a comparison-card edit was retained at an unchanged score of 7.0, and the next Memory decision stopped. Targeted and Planner-only finished at 6.3. In Case 03, both planned routes finished above Targeted, so their gap cannot be assigned entirely to historical cards.

Sparse experience, imperfect applicability judgments and constrained edit scope are testable explanations, not established causes. Planning adds calls and token cost; this batch is not an equal-total-compute comparison.

Exploratory classmate interviews concern a separate set of materials. Their participant identities, item choices and manuscript/branch mapping have not been reconciled. They are qualitative motivation, not a human evaluation of these six exact outputs. No human accuracy or preference percentage is reported here.
