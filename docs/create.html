Which APIs work in a browser?

The provider must support the OpenAI-compatible Chat Completions format and allow browser requests from this site (CORS). Some services block direct browser access. A blocked request cannot be fixed by changing your prompt.

Do not use a public CORS proxy with your API key. If needed, choose another provider or run the local project with a trusted backend.

Evidence first.
Memory with conditions.

  1. Draft from your sources.The model develops a proposal from supplied notes. It does not search the web or run experiments.
  2. Compare revision routes.Targeted uses feedback. Planner-only plans bounded changes. Memory adds conditional editing cards.
  3. Keep an inspectable record.Scores, content checks and retain-or-reject decisions remain available to download.

Memory is a design hypothesis, not a promised improvement. The full comparison shows every branch, including ties and losses.

Compose

What should the proposal investigate?

Up to 1,600 characters.

Supply 2–10 notes, at most 4,000 characters per note and 24,000 characters in total. Long inputs are rejected, not silently shortened. Start each with [S1] Title, then its content; use a new numbered heading for the next source. Only the notes you provide are used as evidence. PDF upload is not supported here.

Full comparison makes up to 21 model calls and can take several minutes. Draft only makes 3 calls for a shorter first run. Provider usage is billed to your account.

Nothing is submitted until you start.
