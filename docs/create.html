Set up Ollama for this website
  1. Download and extract the local connector bundle. Open Start_Windows.bat or Start_Mac.command and choose the full setup.
  2. The first setup downloads the required runtime and approximately 4.7 GB of model weights. Existing project model files can be reused. Keep its terminal open; choose the displayed Ollama address, normally the private service on port 11436. Do not start another copy if it is already running.
  3. Click Test local Qwen. If Chrome or Edge asks to connect to this computer or local network, allow it for this site.
