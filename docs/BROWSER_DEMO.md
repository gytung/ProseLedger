# Browser writing workspace

Open [ProseLedger](https://gytung.github.io/ProseLedger/create.html) to generate and revise a research proposal with your own model API key. The current workflow runs from initial draft through section revision, verification, bounded repair and a retained final manuscript.

See [the complete workspace guide](REVISION_WORKSPACE.md) for inputs, provider access, checkpoints, downloads, optional GPTZero checks and limits.

The [earlier browser comparison guide](BROWSER_COMPARISON_ARCHIVE.md) documents the archived three-route experiments only. Its scores and memory-card behavior do not describe the current workspace.
